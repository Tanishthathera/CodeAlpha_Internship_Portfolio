# Pro Music Player | CodeAlpha Internship Task

A modern, responsive music player built with Vanilla JavaScript that fetches real-time music data using the **iTunes Search API**.

## Features
- **Dynamic Search:** Search for any artist, song, or album globally.
- **Real-time API Fetching:** Retrieves high-quality 30-second audio previews and album art from Apple iTunes.
- **Glassmorphism UI:** A sleek, futuristic design with blurred backgrounds and neon accents.
- **Playback Controls:** Play/Pause, Volume Control, and a dynamic Progress Bar.
- **Interactive Animations:** Rotating album art disc that spins when music is playing.

## Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Advanced styling using Flexbox, CSS Variables, and Glassmorphism.
- **JavaScript (ES6+):** - `Fetch API` for asynchronous data handling.
  - `Audio Object` for playback management.
  - `DOM Manipulation` for real-time UI updates.

##  How to Use
1. Enter the name of a song or artist in the search bar.
2. Click the search icon or press Enter.
3. Click on any result to load it into the player.
4. Use the Play button to start the music and the slider to adjust the volume.

##  API Limitation Note
This project uses the free tier of the iTunes Search API, which provides **30-second high-quality previews** for all tracks. This is ideal for demonstration and testing purposes.
