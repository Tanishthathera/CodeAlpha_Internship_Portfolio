# Smart Glassmorphism Calculator | CodeAlpha Internship Task

A sleek, modern, and fully functional web-based calculator featuring a futuristic **Glassmorphism UI** and advanced JavaScript logic.

##  Features
- **Glassmorphism Design:** Uses backdrop filters and subtle borders for a modern frosted-glass effect.
- **Mathematical Logic:** Handles basic and complex arithmetic operations including percentages and toggling positive/negative values.
- **Keyboard Support:** Allows users to perform calculations using their physical keyboard (NumPad).
- **Responsive Layout:** Perfectly optimized for desktops, tablets, and smartphones.
- **Error Handling:** Robust logic to prevent syntax errors during calculation.

##  Tech Stack
- **HTML5:** Semantic structure for accessibility.
- **CSS3:** - `CSS Grid` & `Flexbox` for layout.
  - `Backdrop-filter` for the glass effect.
  - `Transitions` for button hover animations.
- **JavaScript (ES6+):** - `eval()` based calculation logic.
  - `Event Listeners` for both click and keydown events.

##  Key Functions
- `appendCharacter()`: Updates the display as the user types.
- `calculate()`: Processes the string and returns the mathematical result.
- `clearDisplay()`: Resets the calculator.
- `deleteLast()`: Removes the last character typed (Backspace logic).
